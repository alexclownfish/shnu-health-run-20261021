# Quickstart

1. 使用 `qr-payloads.md` 的五个代码块分别生成纯文本 QR，每张包含提示及原数据两行，必须保留中间换行。可直接使用 `assets/qr-checkpoints/` 的生成图片。原HRQ1身份不变，旧单行码在新版小程序中可继续使用。
2. 先编译新版小程序并上传新体验版，再替换带提示的标牌；旧体验版不识别新格式。二维码提示不会重置当前路线进度，旧 v2 数据仍不会迁入或删除。
3. 从小程序内点击起点扫码。任务点或终点码必须拒绝；起点成功后进入路线第一任务点。
4. 依次完成任务 001、002、003 的扫码和照片上传，第三点后进入终点扫码页，不得直接解锁凭证。
5. 扫描 999 终点，显示凭证的完成时间和总用时，保存相册后核对海报时间相同。
6. 重进、取消、拒绝权限、重复扫码、错顺序、页面卸载后的回调均检查；过程中关闭后重开，开始时间不变。
7. 完赛后重进确认结束时间固定。仅“我的 -> 重置本次路线”可开始新一轮测试。

总用时是起终点扫码的手机时间差，不暂停。微信首页“扫一扫”识别这种纯文本码不会完成打卡，须用小程序内按钮。
